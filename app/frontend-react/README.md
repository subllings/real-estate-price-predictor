# Recreate React Frontend Environment

Follow these steps to reset and run the React environment in the `app/frontend-react` directory.
Run a Git Bash window with administrator privileges

## Navigate to the project folder

```bash
cd /e/_SoftEng/_BeCode/real-estate-price-predictor/app/frontend-react
```

## (Optional) Clean existing environment

```bash
rm -rf node_modules package-lock.json
```

## Install project dependencies

```bash
npm install
```

## Start the development server

```bash
npm start
```
