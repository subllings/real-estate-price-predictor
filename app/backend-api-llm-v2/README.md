# backend-api-llm-v2

This is a FastAPI backend to interact with an LLM (e.g. Azure OpenAI).  
It is ready for local development, Docker deployment, and Azure integration.



##  How to run locally (from terminal)

### 1. Open your terminal

### 2. Change directory to the API folder

```bash
cd app/backend-api-llm-v2
```

uvicorn main:app --reload
